# #67 Journal focusApp and TaskChute

`feat: ジャーナルにフォーカス中のアプリと TaskChute の作業中タスクを記録する` (`feat/journal-focus-tcc`, base `main`). Every journal JSONL line gains `focusApp` (`{name,bundleId,exe,pid}` of the app in front when the `Dictation` was created; Mac takes `Dictation.target`, set from `NSWorkspace.shared.frontmostApplication` at creation) and `taskchute` (`{name,id,startedAt,source:"file",readAt}` read at append time from `dictation.journalTaskFile`, JSON or first non-empty line, 4096-byte cap, anything unusable is `null`). `schemaVersion` stays 1.

## Sub-features

- `jc-history`: the automatic session reached local history (`dictation recognition: complete`).
- `jc-journal-written`: a line was appended under `journalDir`.
- `jc-schema`: `"schemaVersion":1`.
- `jc-task-plain`: plain-text task file → `"taskchute":{"name":"PRマージ検証タスク","id":null,"startedAt":null,"source":"file"` (leading blank line and indentation skipped, second line ignored).
- `jc-focus-present`: `focusApp` is not `null`.
- `jc-focus-pid`: `focusApp` has a `pid`.
- `jc-focus-not-superwhisper`: the recorded app is not Superwhisper.

## How to get to it (user POV)

Set `dictation.journalTaskFile` to a file an updater keeps current, dictate while an editor is in front, open today's `.jsonl`: `focusApp.name` is the editor, `taskchute.name` is the task. Delete the file and dictate again: `taskchute` is `null` and the text is still recorded.
