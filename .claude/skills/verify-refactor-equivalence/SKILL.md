name: verify-refactor-equivalence
description: 機能を変えない構造変更で、変更前と現在の振る舞いを比較する。リファクタリングの PR 前に使う。
---

リポジトリのルートで `sh tests/equivalence.sh <基準コミット>` を実行する。基準コミットを一時 worktree に取り出し、現在の作業ツリー（未コミットの編集を含む）と比較する。

`DIFF` が出た項目は差分の先頭を確認する。実行時エラーは差分検査を失敗させる。パリティ検査の既存の設定・CLI 契約違反は、両方の終了コードと出力が完全に一致した場合に限り `SAME` とし、件数も表示する。`SKIP` は実行環境の不足を示す。完全な比較には macOS、Swift、.NET SDK、Kyoko 音声、Whisper モデル、HUD を表示できるデスクトップが必要。

CLI の受付表とメニュー名はソースから取得し、4 つの CLI モードをリリースバイナリで実行する。設定キーとウェイク動作種別はバイナリの Swift メタデータから取得し、利用できない場合はソースを参照する。Windows 固有の CLI と実機のマイク操作は別途確認する。
