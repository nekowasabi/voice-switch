# 追加評価結果（2026-10-03）

既存の任意オプション ConservativeWiener 6 dB は、弱い合成白色雑音で停止認識を改善し、清音20例ではOffと同一の本文・出力を保持した。効果は条件限定であり、既定値はOffを維持する。新しいフィルターの本体採用、通常配置先への展開、実マイク・Superwhisperの使用は行っていない。

## 認識精度

集計CERは22.3% / 14.2% / 16.2%。6 dBでもハム30の本文1文字が悪化している。白色20ではOffのウェイク失敗2例があり、その他の停止失敗と区別している。全72例で本文・停止リクエストは分離し、結合発話・本文欠落・認識エラー・タイムアウト・原音整合性失敗はない。

白色35の同じ3波形をOff/6 dBで再実行した別枠6例では、停止 **0/3対3/3を再現**。本文編集数は両方5/37で一致した。これは結果を見て選んだ条件の追試であり、主試験72例と分母を合算しない。

別枠の清音20例（速度・間隔違い）では6 dBも停止20/20。Offと出力範囲、実際のWAV/PCMハッシュ、各本文仮説が20/20一致し、CERは双方4/246=1.63%。既知の本文末尾20/20・独立に構成した本文全体2/2を保持。残る18例は本文の音響開始点の独立ラベルがなく、あらゆる本文の保持を証明しない。停止音の厳密なゼロ重複は4/20のままで、16例の非常に弱い0.375–15msの立ち上がり残留も変わらない。清音のゼロに近い雑音PSDではほぼ無処理になりうるので、雑音中の音声保存への一般化はできない。

## DSP・音響・時間

既存処理は16kHz PCM16、320サンプル平方根Hann、160ホップ、FFT512のdecision-directed spectral Wiener。50連続quiet hopでPSD初期化（raw RMS<.005）、speech後30hop学習停止、PSD beta=.9900498337491681、prior alpha=.96、gain下限10^(-attenuationDb/20)。最大6 dB、既定Off。実装・評価法は [Windows DSP evaluation method](./windows-dsp-evaluation-method.md) を参照。

24入力×5処理=120音響測定。全120で入力原音の同一性、連続フレーム、サンプル数一致、飽和0を確認。定常雑音のみのprefix/tail区間で6 dB処理は平均5.90–5.98 dB、3 dB処理は2.98–3.00 dB減衰した。6 dBの原清音との波形誤差SNRは白色35で34.86→37.28 dB、白色20で19.86→23.81 dB、ハム20で19.87→24.05 dB。位相・歪みを含む波形指標であり、知覚品質やASR改善そのものではない。

## 代替案と採否

既存依存のみで隔離したnet8プローブを作成。60+120Hz notch各Q20と80Hz high-pass Q=1/√2は標準biquad、[W3C Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)に基づく。7自己テストと独立レビューを通過。notchはハムを51–64 dB抑えるが、認識改善を意味しない。

清音・ハム20・ファン25・白色30の12入力×2案=24認識試行では、双方停止9/12でOffと同じ、白色30は全て0/3。HP80は清音本文の末尾「す」を欠落、notchはハム本文の「す」を「四」に変更した。**どちらも採用しない。** フィルター出力を認識器へ渡す隔離ASR代理試験であり、原音引渡し経路の検証とは区別する。

6 dBは任意オプションとして保持するが既定Off。DSP対象はSAPIの解析・制御用音声のみで、引渡し音声は雑音を含む原PCM。本文CERはSuperwhisperの最終文字起こし品質を示さず、引渡しファイルのノイズ除去も行わない。
